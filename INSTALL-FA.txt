راهنمای سریع نصب — Vault SSH Bridge
=====================================

۱) پوشه‌ی زیر را در خزانه‌ی اوبسیدین خود بسازید (اگر نیست):

   <خزانه-شما>/.obsidian/plugins/vault-ssh-bridge/

   توجه: نام پوشه باید دقیقاً vault-ssh-bridge باشد.

۲) محتویات پوشه‌ی plugin این بسته (manifest.json و main.js و styles.css و README.md)
   را داخل همان پوشه کپی کنید.

۳) اوبسیدین را باز کنید و به تنظیمات بروید:
   Settings → Community plugins
   اگر حالت محدود (Restricted mode) روشن است، خاموشش کنید.
   سپس پلاگین «Vault SSH Bridge» را Enable کنید.

۴) تمام! سرور SSH اجرا می‌شود.
   - وضعیت: نوار پایین چپ، علامت سبز SSH:2222
   - نام کاربری و رمز: Settings → Vault SSH Bridge
   - رمز پیش‌فرض هنگام اولین اجرا تصادفی ساخته شده؛ آن را ببینید یا عوض کنید.

۵) اتصال از ترمینال:

   ssh ai@127.0.0.1 -p 2222

   بعد از ورود: قوانین سرور نمایش داده می‌شود.
   دستور help → لیست دستورات
   دستور rules → مشاهده‌ی قوانین

۶) اتصال هوش مصنوعی «خارجی» (بیرون از همین کامپیوتر):

   الف) دستگاه دیگر در همان وای‌فای:
       تنظیمات → «دامنه‌ی اتصال» → همه‌ی شبکه → سرور را دوباره شروع کنید.
       پلاگین آی‌پی واقعی کامپیوتر را پیدا می‌کند و در پنجره‌ی
       «اطلاعات اتصال» فرمان آماده می‌دهد، مثل:
       ssh ai@192.168.1.10 -p 2222

   ب) هوش مصنوعی روی اینترنت (بدون تنظیم مودم):
       تنظیمات → «دسترسی خارجی» → «تونل عمومی» → pinggy.io
       سرور را شروع کنید؛ یک نشانی عمومی موقت مثل
       ssh -p 43210 ai@abcdef.a.pinggy.io
       ساخته می‌شود که از هر جای دنیا کار می‌کند.
       (نیازمندی: کلاینت OpenSSH — ویندوز ۱۰+ / مک / لینوکس دارند.
        تونل رایگان pinggy حدود ۶۰ دقیقه فعال می‌ماند.)

   ج) کپی پرامپت آماده: پنجره‌ی «اطلاعات اتصال» → بخش
      «پرامپت آماده برای هوش مصنوعی» → کپی پرامپت.

۷) برای دادن به هوش مصنوعی، فایل AI-PROMPT-FA.txt را ببینید.

نکته امنیتی: پیش‌فرض فقط همین کامپیوتر (localhost) قابل اتصال است.
برای اتصال خارجی، رمز قوی بگذارید؛ محافظت شکست رمز (مسدودسازی IP
بعد از تلاش‌های ناموفق) به‌صورت پیش‌فرض روشن است. بعد از کار،
تونل را خاموش و دامنه را روی localhost برگردانید.
