نمونه پرامپت برای دادن به دستیار هوش مصنوعی
=============================================
جای <PORT> و <USERNAME> و <RAMZ> را با مقادیر تنظیمات پلاگین عوض کنید
(پیش‌فرض: پورت ۲۲۲۲، نام کاربری ai).

------------------------------------------------------------
می‌خواهم از طریق SSH به خزانه‌ی اوبسیدین من وصل شوی و کاری را انجام دهی.

فرمان اتصال (تک‌فرمانی):
  ssh <USERNAME>@127.0.0.1 -p <PORT> "<COMMAND>"
نمونه: ssh ai@127.0.0.1 -p 2222 "ls"

نام کاربری: <USERNAME>
رمز عبور: <RAMZ>

قوانین که باید رعایت کنی:
۱) ابتدا با فرمان "rules" قوانین سرور را بخوان و با "help" لیست دستورات را ببین.
۲) فقط از دستورات خود این سرور استفاده کن:
   ls, cd, pwd, cat, head, tail, write, append, mkdir, rm, mv, cp,
   find, grep, tree, recent, stat, info
۳) پیش از بازنویسی هر فایل، اول محتوای فعلی‌اش را با cat بخوان.
۴) دسترسی فقط داخل خزانه است؛ دستور سیستم‌عاملی (مثل bash) کار نمی‌کند.
۵) برای ساخت فایل جدید از write و برای افزودن از append استفاده کن؛
   در متن‌ها از n\ برای خط جدید استفاده کن.

حالا این کار را انجام بده:
<کار مورد نظر شما را اینجا بنویسید>
------------------------------------------------------------

نمونه‌ی چند فرمان آماده:

  ssh ai@127.0.0.1 -p 2222 "rules"
  ssh ai@127.0.0.1 -p 2222 "ls"
  ssh ai@127.0.0.1 -p 2222 "cat projects/ideas.md"
  ssh ai@127.0.0.1 -p 2222 "write daily.md # دوشنبه\nامروز گزارش پروژه را نوشتم"
  ssh ai@127.0.0.1 -p 2222 "grep جلسه"
  ssh ai@127.0.0.1 -p 2222 "recent 5"
